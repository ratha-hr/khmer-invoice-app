ពិនិត្យផ្ទៀងផ្ទាត់វិក្កយបត្រ

ការណែនាំអំពីការបោះពុម្ព និងរក្សាទុកជា PDF (A4)

ដើម្បីទទួលបានវិក្កយបត្រទំហំ A4 ស្អាតឥតខ្ចោះ (Pixel-Perfect) សូមអនុវត្តតាមការកំណត់ខាងក្រោមនៅពេលផ្ទាំង Print បង្ហាញឡើង៖

  • គោលដៅ (Destination): ជ្រើសរើស Save as PDF (ឬជ្រើសម៉ាស៊ីនព្រីនរបស់អ្នក)
  • ទំហំក្រដាស (Paper size): ជ្រើសរើស A4
  • ទិសដៅក្រដាស (Layout): ជ្រើសរើស Portrait (បញ្ឈរ)
  • កម្រឹមក្រដាស (Margins): ជ្រើសរើស Default ឬ None
  • ជម្រើសពណ៌ (Options): គូសធីកលើ "Background graphics" (ដើម្បីឱ្យចេញពណ៌ក្បាលតារាង និងពណ៌ស្អាត)
  • ក្បាល និងបាតទំព័រ (Headers and footers): ដោះធីកចេញ (Uncheck) ដើម្បីកុំឱ្យជាប់តំណភ្ជាប់ URL និងកាលបរិច្ឆេទលើក្បាលទំព័រ
💡 គន្លឹះ៖ អ្នកក៏អាចចុចបញ្ជាផ្ទាល់តាមរយៈប៊ូតុងកាត់ Ctrl + P នៅលើក្តារចុចបានគ្រប់ពេលវេលា។
